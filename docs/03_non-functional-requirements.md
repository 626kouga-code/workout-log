# 非機能要件

[目次に戻る](README.md)

| 区分 | 要件 |
| --- | --- |
| セキュリティ | 通信はすべて HTTPS。パスワードは bcrypt（コスト 12）でハッシュ化して保存する |
| セキュリティ | ログイン状態は Auth.js のセッションで管理し、セッション ID は HttpOnly・Secure・SameSite=Lax の Cookie に入れる。DB にはセッションの有効期限を持たせ、ログアウトで削除する |
| セキュリティ | 更新処理（Server Actions）は Next.js の Origin 検査で CSRF を防ぐ。Route Handlers で更新を受け付けるものは、同じ Origin からのリクエストだけを受け付ける |
| セキュリティ | 認可（本人のデータか）はすべてサーバー側で確認する。トレーニング記録・メニュー・体重は、取得の時点で「ログイン中のユーザーのものだけ」に絞り込む。他人の ID を指定された場合は、存在を知らせないよう 404 を返す |
| セキュリティ | メールアドレス確認のトークンは推測できない乱数（32 バイト）で作り、DB には SHA-256 のハッシュだけを保存する。有効期限は 24 時間で、1 回使ったら無効にする |
| セキュリティ | 退会（F-06）にはパスワードの再入力を必須にする。退会処理は DB のトランザクションで行い、S3 の画像は DB の削除が成功した後に消す（失敗した画像は定期的に掃除する） |
| メール | 送信元アドレスは独自ドメインまたは SES で検証したアドレスにする。送信に失敗しても登録自体は完了させ、再送で対応できるようにする |
| セキュリティ | 入力値は Zod のスキーマでサーバー側でも必ず検証する（画面側の検証だけに頼らない） |
| セキュリティ | XSS 対策として、投稿本文・コメントは React の標準エスケープで表示し、HTML としては描画しない |
| セキュリティ | （Could：講義用のため MVP では行わない）レート制限：ログイン試行は 1 IP あたり 10 回/10 分、投稿は 1 ユーザーあたり 30 件/時 |
| 画像 | アップロードはサーバーを経由する。ファイルの中身から形式を判定し、sharp で Exif を除去し、向きを補正して、表示用（長辺 2048px）とサムネイル（長辺 640px）を WebP で作ってから S3 に保存する |
| 性能 | タイムラインの初回表示は 2 秒以内（同時接続 50 ユーザー時）。一覧はカーソル方式のページング（20 件単位） |
| 性能 | 記録画面のセット入力は端末に保存し、サーバーの応答を待たずに画面へ反映する。送信に失敗しても入力は消えず、自動で再送する |
| 性能 | グラフ・自己ベストの集計は、1 ユーザーの 3 年分の記録（約 500 ワークアウト、2 万セット）で 1 秒以内に返す |
| 対応環境 | スマートフォン（iOS Safari、Android Chrome の最新版）を主な対象とする。PC の最新ブラウザ（Chrome / Edge / Safari / Firefox）でも使える。画面幅 360px 以上でレイアウトが崩れないこと |
| 操作性 | 記録画面は片手で操作できるよう、主要なボタンを画面下部に置き、タップ領域は 44px 以上にする |
| PWA | Web App Manifest と Service Worker を用意し、ホーム画面に追加すると全画面（standalone）で起動する。画面の静的ファイルはキャッシュする。記録画面（S-11）だけはオフラインでも開け、入力は端末に保存して通信が戻ったら自動で送る（F-16）。それ以外の画面は、オフライン時に「オフラインです」と表示する |
| PWA | 端末（IndexedDB）に保存するデータは、本人の記録に必要なものに限る。ログアウト時に消去する（送信待ちの変更があれば、警告して送信してから消す） |
| PWA | 記録中は Screen Wake Lock API で画面のスリープを防ぐ（対応ブラウザのみ。設定で切り替えられる） |
| 時刻・単位 | DB には UTC で保存し、画面では日本時間（Asia/Tokyo）で表示する。「実施日」は日本時間の日付で扱う。重量は kg のみ |
| 可用性 | AWS の環境は動作確認・発表のときだけ作るため、常時の稼働は求めない。環境を作っている間は、利用者が使える状態を保つ（目安として、障害時は 30 分以内に作り直せること） |
| 法務 | 講義課題向けの簡易版の利用規約・プライバシーポリシーを、公開前に用意する（扱うデータ、公開範囲、動作確認用のサービスであること、退会時の削除）。体重・体脂肪率は本人以外に公開しないこと、退会するとすべてのデータを削除し、復元できないことを明記する |

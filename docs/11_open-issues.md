## 設計

- [x] **ID の格納形式**：2026-11-23 に決定。UUIDv7 を `CHAR(36)` で持つ。DB を直接見ても読めること、Prisma で変換なしに扱えること、数十人規模なら容量の差が問題にならないことから選んだ（[データモデル](05_data-model.md)）
- [x] **ローカルの S3 互換ストレージ**：2026-11-23 に決定。S3Mock（SNSアプリで動作実績がある）
- [x] **プリセット種目の一覧**：2026-11-23 に決定。36 種目（[機能要件の付録](02_functional-requirements.md#付録プリセット種目一覧)）
- [x] **自己ベストの定義**：2026-11-23 に決定。最大重量・推定 1RM・重量ごとの最大回数の 3 種類。同じ重量で回数が増えた場合（例：80kg × 8 → 80kg × 10）も自己ベストとして扱う。時間種目は最長時間（[F-32](02_functional-requirements.md)）
- [x] **タイマーの通知**：2026-11-23 に決定。MVP では「画面を開いていれば振動と音」「アプリに戻ったときに終了を表示」までとし、画面オフ時の Web Push は Could（[F-25](02_functional-requirements.md)）
- [x] **記録中のデータの保存方法**：2026-11-23 に決定。まず端末（IndexedDB）に保存し、通信できるときに自動でサーバーへ送る。圏外のジムでも記録を続けられる（[F-16](02_functional-requirements.md)、[同期の仕組み](06_api.md#記録中のデータの同期)）
- [x] **メール未確認のときにできる操作**：2026-11-23 に決定。記録・閲覧・プロフィール編集・退会はできる。SNS の操作（投稿・コメント・いいね・フォロー）と通知の確認はできない（[F-02](02_functional-requirements.md)）
- [x] **未確認のアカウントの扱い**：2026-11-23 に決定。自動では削除しない
- [x] **投稿の画像形式**：2026-11-23 に決定。GIF は受け付けない（JPEG / PNG / WebP のみ）
- [x] **時間で記録する筋トレ種目**：2026-11-23 に決定。MVP で扱う。種別に「時間（TIMED）」を追加し、プランク・サイドプランクをプリセットに入れる。自己ベストは最長時間

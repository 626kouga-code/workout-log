# 機能要件

[目次に戻る](README.md)

優先度：**Must** = MVP に必須 / **Should** = 次リリース / **Could** = 余裕があれば

このアプリは講義の課題として作るため、不特定多数向けの運用に必要な機能（F-04・F-05・F-87〜F-89）は Could とし、MVP では作らない。必要になったら優先度を戻す。

## 認証・アカウント

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-01 | 新規登録 | メールアドレス、パスワード（8 文字以上）、ユーザーID（@handle、英数字と `_`、3〜15 文字、大文字小文字を区別せず一意）、表示名（50 文字以内）を登録する。利用規約とプライバシーポリシーへの同意を必須にする | Must |
| F-02 | メールアドレス確認 | 登録時に確認リンク（有効期限 24 時間、1 回限り）を送る。確認が済むまでは、トレーニング・体重の記録と閲覧はできるが、SNS の操作（投稿・コメント・いいね・フォロー）はできない。未確認の間は画面上部に案内を表示し、確認メールを再送できる（再送は 1 分に 1 回まで） | Must |
| F-03 | ログイン／ログアウト | メール＋パスワードでログインする。ログイン状態は 30 日間保持する。ログアウトするとセッションを無効化する | Must |
| F-04 | Google ログイン | Google アカウントでログイン・登録する | Could |
| F-05 | パスワードリセット | 登録メールに再設定リンク（有効期限 1 時間、1 回限り）を送る | Could |
| F-06 | 退会 | パスワードを再入力したうえで、アカウントと、記録・メニュー・体重・投稿・画像（S3 上のファイルを含む）・いいね・フォロー・通知をすべて削除する。返信が付いたコメントは本文を消し、「削除されたユーザー」として残す。退会後は同じメールアドレス・ユーザーIDで登録し直せる | Must |

## トレーニング記録

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-10 | 種目マスタ（プリセット） | 代表的な種目（36 種目。[付録](#付録プリセット種目一覧)）を最初から用意する。各種目は部位（胸・背中・脚・肩・腕・腹・全身・有酸素）と種別（重量・自重・有酸素・時間）を持つ | Must |
| F-11 | 種目の追加・編集 | 自分専用の種目を名前（30 文字以内）・部位・種別を指定して追加・編集・削除できる。記録で使用中の種目は削除できず、「非表示」にできる | Must |
| F-12 | ワークアウトの記録 | 実施日、開始・終了時刻、メモ（500 文字以内）を持つワークアウトを作る。種目を追加し、セットごとに入力する。重量種目は重量（0〜999.75kg、0.25kg 刻み）と回数（1〜999）、自重種目は回数（＋任意で加重 kg）、有酸素は時間と距離（任意）、時間種目（プランクなど）は秒数（＋任意で加重 kg）。セットごとに「完了」をチェックできる | Must |
| F-13 | 入力の補助 | 種目を追加すると、その種目の前回の記録（重量・回数・セット数）を初期値として表示する。直前のセットを複製して新しいセットを追加できる。重量は ±2.5kg のボタンでも変えられる | Must |
| F-14 | ワークアウトの編集・削除 | 自分のワークアウトをあとから編集・削除できる。投稿に添付されたワークアウトを削除すると、投稿からは添付が外れる（投稿自体は残る） | Must |
| F-15 | 履歴 | 自分のワークアウトを、月表示のカレンダー（実施日に印を付ける）とリスト（新しい順、20 件ずつの無限スクロール）で表示する。種目・部位で絞り込める | Must |
| F-16 | 圏外での記録と自動送信 | 記録中の入力は、まず端末（IndexedDB）に保存し、通信できるときに自動でサーバーへ送る。ジムが圏外でも、開始から終了まで記録を続けられる。送信待ちがある間は、記録画面に「未送信 n 件」と表示する。ブラウザを閉じたり再読み込みしたりしても続きから再開できる。同じワークアウトを複数の端末で変えた場合は、後に変更したほうを採用する（詳細は[サーバー処理](06_api.md#記録中のデータの同期)） | Must |
| F-17 | ワークアウトの複製 | 過去のワークアウトを複製して、今日の記録として始められる | Should |

## 進捗・自己ベスト

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-30 | 種目別グラフ | 種目を選び、日ごとの最大重量・推定 1RM・総ボリューム（重量×回数の合計）を折れ線グラフで表示する。期間は 1 か月・3 か月・1 年・すべてから選ぶ | Must |
| F-31 | 推定 1RM | Epley 式（重量 ×（1 + 回数 ÷ 30））で計算する。回数が 1 のときは重量そのもの。回数が 13 以上のセットは計算に使わない | Must |
| F-32 | 自己ベスト一覧 | 種目ごとに次の 3 種類の自己ベストを、達成日とあわせて一覧表示する。①**最大重量**（回数を問わず、最も重い重量）、②**推定 1RM**（F-31 の最大値）、③**重量ごとの最大回数**（例：80kg で 8 回 → 10 回に伸びたら更新。重量が完全に一致するセット同士で比べる）。自重種目は③を「回数ごと」ではなく「最大回数」として扱う（加重がある場合は加重の重量ごと）。時間種目は最長時間を自己ベストとする（加重がある場合は加重の重量ごと）。有酸素は自己ベストの対象外 | Must |
| F-33 | 自己ベスト更新の表示 | 記録中に自己ベストを更新したセットに「PR」バッジを、種類（最大重量／1RM／回数）付きで表示する。圏外でも端末内の記録と比べて表示し、送信後にサーバーの判定で確定する。ワークアウトの終了時に、更新した自己ベストをまとめて表示する。その種目の初めての記録は、自己ベストとして数えない | Must |
| F-34 | 週間サマリー | 直近 8 週間の、週ごとのトレーニング日数と総ボリュームを棒グラフで表示する。部位別の割合も表示する | Must |

## 投稿・タイムライン

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-50 | テキスト投稿 | 本文は 1〜280 文字。画像かワークアウトが添付されていれば、本文なしでも投稿できる | Must |
| F-51 | 画像投稿 | 1 投稿に最大 4 枚。JPEG / PNG / WebP、1 枚 10MB まで（GIF は受け付けない）。サーバーで Exif（位置情報など）を除去し、表示用（長辺 2048px）とサムネイル（長辺 640px）を作る。一覧ではサムネイルを表示し、タップで拡大する | Must |
| F-52 | ワークアウトの添付 | 自分のワークアウトを 1 件まで添付できる。添付すると、種目ごとのサマリー（例：「ベンチプレス 80kg × 8 回 × 3 セット」）、総ボリューム、トレーニング時間、そのワークアウトで更新した自己ベストをカードで表示する。ワークアウトの終了画面から「投稿する」を選ぶと、添付した状態で投稿画面を開く | Must |
| F-53 | 投稿削除 | 自分の投稿だけ削除できる。付いていた画像・いいね・コメントも削除する。添付していたワークアウトは削除しない。投稿の編集はできない | Must |
| F-54 | 投稿詳細 | 本文、画像、添付ワークアウト、いいね数、コメント数、コメントを表示する | Must |
| F-55 | ホームタイムライン | 自分とフォロー中のユーザーの投稿を新しい順に表示する。20 件ずつの無限スクロール。ログイン時のトップ画面にする | Must |
| F-56 | 全体タイムライン | 全ユーザーの投稿を新しい順に表示する。未ログイン時のトップ画面にする | Must |
| F-57 | 新着表示 | 表示中の先頭より新しい投稿を 30 秒ごとに確認し、あれば「新しい投稿があります」と表示する。タップで反映する。自分の投稿は数えない | Must |
